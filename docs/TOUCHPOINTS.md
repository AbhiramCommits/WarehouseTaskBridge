# Failure-mode touchpoints

Every failure the bridge is designed to absorb, where it is detected, what the
system does, where the evidence is observable, and the test that proves it.

| Failure mode | Detection mechanism | System response | Persisted / observable | Proving test |
| --- | --- | --- | --- | --- |
| Unknown message (unmappable order kind) | `translate.kindByExternal` lookup misses | Accept the order as `TASK_TYPE_UNKNOWN`; never drop routable work; emit `UNMAPPED_KIND` warning | `/v1/reconciliation`, reconciliation report, bridge log | `TestToInternalMapping/unknown_kind_accepted` |
| Malformed payload | JSON decode failure or missing required fields | Insert into `quarantine`, mirror raw bytes to `wms.quarantine`, ACK the NATS message / return 400 to REST | `quarantine` table, `wms.quarantine`, `quarantined` counter | `TestAcceptOrderQuarantinesBadInput/malformed_json`, `TestMalformedAndUnknownSchemaQuarantine` |
| Duplicate order | `INSERT ... ON CONFLICT (idempotency_key) DO NOTHING RETURNING id` returns no row | Keep the original task, return its id with `created=false`, increment `orders_deduped` | `tasks` unique key, REST 200 with existing id, `/metrics` | `TestAcceptOrderCreatesOnceAndDedupes`, `TestDuplicateStormAcrossTransports` |
| Conflicting duplicate | Stored payload hash differs from the replayed payload hash | Quarantine the replay as `CONFLICTING_DUPLICATE`, keep the original task untouched, return the original id | `quarantine` row, warning on the accept result, `quarantined` counter | `TestAcceptOrderConflictingDuplicate` |
| Redelivered message | JetStream redelivery after NAK / ack timeout | Same idempotency path: exactly one task row, one outbox row per transition; no duplicate `StateSeq` | `tasks` count, `task_events.seq`, WMS status stream | `TestRedeliveryIsIdempotent` |
| Peer silence | No `wms.heartbeat` for `PEER_SILENCE_TIMEOUT` | Log a structured warning, increment `peer_silence_events`, pause publishing and buffer unpublished events in seq order; drain on recovery | `/metrics` (`peer_silence_events`, `events_buffered`, `events_drained`), `peer_heartbeats` table | `TestWatcherSilenceDetection`, `TestPublisherHonorsPeerSilence`, `TestPeerSilenceBuffersAndDrains` |
| DB unavailable | Task insert or quarantine write returns a pgx error | Return a transient error: NATS NAKs with delay for safe redelivery; REST returns 503; no partial state | NATS consumer delivery count, bridge log, `/healthz` degradation | `TestAcceptOrderTransientStoreFailure`, `TestRedeliveryIsIdempotent` |
| Publish-ack failure | JetStream publish returns an error or the ack never arrives | Leave `published=false`, retry with exponential backoff; a later retry republishes the same seq | `task_events.published`, `publish_failures`, WMS may see a replay with the same `StateSeq` | `TestPublisherNoLossOnPublishFailure`, `TestPublisherAtLeastOnceDuplicateCarriesSameStateSeq` |
| Illegal state transition | Explicit transition table in `scheduler/state.go` | Reject before touching the database; return `ErrIllegalTransition`; never silently apply | Returned error, no `tasks` or `task_events` mutation | `TestStateMachineTransitionTable`, `TestMachineRejectsIllegalBeforeStore` |
| Unparseable slot | `translate.ParseSlot` rejects anything not `AISLE-BAY-LEVEL` | Hard translation error: quarantine the payload, ACK/400 it, and do not create unroutable work | `quarantine` table with `TRANSLATION_ERROR`, `UNPARSEABLE_SLOT` warning sample | `TestToInternalMapping/bad_source_slot`, `TestAcceptOrderQuarantinesBadInput/unparseable_slot` |
